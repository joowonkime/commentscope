# 관점 비교 사용자 테스트 과업 초안

상태: 준비용 초안. 실제 사용자 테스트와 실제 화면 검증은 아직 수행하지 않았다.
실제 댓글 기반 검토된2 Agent/각지지3개·6응답·HTTP 경로가 준비됐다([전달 자료](COMPARE_BACKEND_DELIVERY.md)). 실제 참가자 테스트와 조원 화면 검증은 아직 수행하지 않았다.
Figma 원본을 편집하거나 새로운 기능을 추가하는 지시가 아니다. API 경로는 [연동 계약](COMPARE_BACKEND_API.md)을 따른다.

진행자는 참가자에게 어느 의견이 정답인지 알려 주지 않는다. 성공 여부와 발언을 구분해서 기록한다.
조작이 막히면 먼저 어디에서 무엇을 기대했는지 듣고 도움을 준 시점을 기록한다.

| 과업 | 참가자에게 전달할 요청 | 관찰할 내용 |
| --- | --- | --- |
| T1 최초 의견 | 이 영상의 기본소득 주제에 대한 현재 의견을 적고 저장해 주세요. | 저장 여부를 이해하는지, 다시 열었을 때 원문이 유지되는지 |
| T2 두 관점 선택 | 서로 다르다고 생각하는 관점 두 개를 골라 주세요. 어떤 차이를 보고 골랐는지도 설명해 주세요. | 카드 이름만으로 같은 관점을 중복 선택한다고 느끼는지, 실제 주장 차이를 설명하는지 |
| T3 같은 질문 비교 | 두 관점 모두에게 같은 질문을 보내 주세요. “이 관점의 주장과 중요한 이유·조건은 무엇인가요?” | 두 답변을 구분하는지, 한 작성자의 이유를 모든 지지자의 공통 이유로 이해하는지 |
| T4 근거 확인 | 답변의 근거를 하나 열고, 이 댓글이 답변을 어디까지 뒷받침하는지 설명해 주세요. 답글이면 부모 댓글도 확인해 주세요. | 작성자·인용·조건·불확실성을 찾는지, 부모의 이유와 답글 작성자의 이유를 구분하는지 |
| T5 근거 밖 질문 | 두 관점에게 “이 자료만으로 한국에서 시행할 기본소득의 정확한 최종 재원은 얼마인가요?”라고 물어 주세요. | 모르는 범위를 명확히 이해하는지, 보류를 오류 또는 검증된 금액으로 오해하는지 |
| T6 판단 회고 | 처음 의견과 비교해 달라지거나 여전히 남은 점을 말해 주세요. 어떤 근거가 영향을 주었나요? | 의견 변화 자체를 성공으로 강요하지 않고, 주장·이유·조건·사실의 구분을 이해했는지 |

T6는 진행자의 기록 과업이다. 자동 성찰, 사용자 의견의 사실 승격, Agent 간 토론 기능을 추가하지 않는다.
초기 의견이 Agent의 댓글 근거로 인용되거나 다른 관점의 이력이 섞이는 경우는 별도 결함으로 기록한다.

| 기록 항목 | 값 |
| --- | --- |
| 검토된 bundle와 버전 / 선택한 실제 관점 ID | 실행 때 기입 |
| 참가자·일시 / 진행 환경 | 실행 때 기입 |
| 과업별 완료·도움 여부 / 걸린 시간 | 미실행 |
| 참가자가 설명한 두 관점의 차이 | 미수집 |
| 잘못 이해한 이유·조건·작성자 / 관련 인용 ID | 미수집 |
| 근거 밖 질문의 답변·보류와 참가자 해석 | 미수집 |
| 다음에 고칠 구체적인 화면·문구와 이유 | 미수집; Figma 변경은 사용자와 별도 논의 |

이 초안은 사용자 테스트 완료 증거나 전체 프론트 구현 완료 증거가 아니다.
