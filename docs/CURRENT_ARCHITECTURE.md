# 현재 구조와 채택 상태

2026-10-13 기준, 실행·추적 기반은 구축했지만 자동 관점 에이전트의 의미 품질은 미완료다.
최근 위치 근거 실험은 정상 손실 때문에 채택하지 않았다. 실험 모듈이 존재한다고 기본 경로에 연결된 것은 아니다.
과거 결정은 [ARCHITECTURE](ARCHITECTURE.md)에 유지하고, 현재 경로와 채택 여부는 이 문서에서 확인한다.

## 목표와 현재 경로

목표는 모든 댓글의 의미를 완벽히 복원하는 것이 아니라, 충분한 원문 근거를 갖춘 관점을 발견해 그 범위를 지키는 agent를 만드는 것이다.
대립 진영이나 고정된 agent 수를 먼저 정하지 않는다. 서비스 실행에 사람이 분류·수정·승인하는 단계는 넣지 않는다.

```text
공식 API 고정 snapshot
  → 원문과 출처 보존
  → 넓은 후보 검색
  → 관점 후보와 공통 주장 제안
  → 원문별 지지 판단
  → 중복 없는 지지도와 불확실성 집계
  → 기준을 충족한 PerspectiveSpec
  → 근거 범위 안에서 답하는 Agent
```

| 부분 | 구현 및 상태 | 유지할 경계 |
|---|---|---|
| 수집·정규화 | 공식 API 1,000개 snapshot, 999 canonical | 현재 표본을 유지하며 전수 수집·여론 대표성을 주장하지 않음 |
| 원문 registry·검색 | 실제64개 보존·검색·대기 목록 구현 | 추출 실패가 원문을 영구 제거하지 않음; 유사도는 지지가 아님 |
| 공통 주장·가입 판정 | 여러 opt-in 비교와 자동 Factory 구현 존재 | 실제 의미 오류·과잉거절 미해결, 최신 실험을 기본값으로 승격하지 않음 |
| 지지 집계 | 고정 주장별 canonical source 집계 코드 존재 | 미검사·불확실·오류를 지지나 반대로 세지 않음 |
| Agent·UI | 개발용 검수 지원 경로와 자동 연결 코드 존재 | 개발용 데모와 자동 품질 승인 완료를 구분 |
| 평가 | 원시 응답·hash·재생·회귀 검사; 새 실제 평가 kit | 테스트 통과와 의미 품질을 구분, 같은 모델의 감사는 독립 gold가 아님 |

실제 모델 구성은 생성형 로컬 LLM뿐 아니라 임베딩 검색과 NLI 비교를 포함한다.
코드 책임은 입력·출처·형식·중복·예산 검증이다. 모델이 선택한 위치가 맞는다는 사실만으로 그 내용의 의미를 승인하지 않는다.

## 서로 다른 세 종류의 정책

| 층 | 유지하거나 변경할 내용 |
|---|---|
| 제품 원칙 | 원문 충실성, 충분한 지지도, 희소 관점 보존, 서비스 중 수동 승인 없음 |
| 강제 가능한 코드 계약 | 원문 ID·slice 검증, 중복 집계 금지, 누락/미검사 명시, 불변 산출물 |
| 교체 가능한 실험 가설 | 단일 eligibility enum, 세부 속성 감사, 단어 위치·참조 그래프, 모델·threshold |

실험 가설을 제품 원칙처럼 고정하지 않는다. 원문 충실성을 유지하기 위해 실패한 검사 구현까지 유지할 필요는 없다.
검사를 추가할수록 정상 손실·호출 비용도 평가한다. 0-agent나 대부분 보류하는 결과를 품질 성공으로 세지 않는다.

댓글의 발화 유형, 주제 관련성, 문맥 충분성, 작성자 입장, 주장의 지지는 서로 다른 평가 질문이다.
이들을 평가표에서 구분한다고 모든 필드를 서비스 LLM에게 한 번에 출력시키는 것은 아니다.
질문·문맥적 반응은 독립 관점이 아닐 수 있지만 삭제하지 않는다. 부모 문맥을 사용할 경우 별도 버전과 출처 경계를 먼저 정한다.

## 공통 주장과 상세 이유

공통 주장의 지지 수와 각 상세 이유의 지지 수를 분리한다. 무료급식에 찬성하지만 각각 비용·영양·접근성을 말하는 댓글이라면,
공통 입장과 원문별 이유를 분리해 표현할 수 있다. 모든 댓글이 모든 이유를 지지한다고 표현하면 안 된다.
중요한 입장·조건 충돌은 split 또는 명시적 차이로 보존한다. 같은 주제라는 이유만으로 같은 관점으로 승인하지 않는다.

초기 핸드오프의 agent 후보 최소3개 출처와 이후 제안된 ‘약5%면 주요 관점 표시’는 다른 기준이다.
전자는 충분조건이 아니고 후자는 확정되지 않은 표시 가설이다. 소수라는 이유로 삭제하지 않으며 댓글 수를 사람 수·여론 비율로 부르지 않는다.

## 최근 판단과 다음 단계

- 위치 근거0.1: 정상 source 통과23/24→5/24, 부정 오승인15/24→1/24. 통과 근거도 불완전해 채택 거부.
- 단일 source-only0.1: 오승인이 남아 기본 필터로 채택하지 않음.
- 8B 비교·OpenJev·추가 감사: 전체 문제 해결 또는 기본 교체 근거를 확보하지 못함.
- 단어 위치 방식의 다음 변형을 즉시 실행하지 않는다. [실제 데이터 평가 프로토콜](FACTORY_EVALUATION_PROTOCOL.md)을 우선한다.
