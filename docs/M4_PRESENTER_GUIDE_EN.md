# Re.View | Studio 4 presenter guide

**The question for the audience**  
Can a viewer trace a claim back to a YouTube comment, question a different perspective and leave with a judgment they can explain?

**Live prototype** [Open Re.View](https://35.212.169.73/mvp) · [Course milestone requirements](https://docs.google.com/document/d/1abUH5BCJjXQnEWujXDdby2AUpD-n28xEPGv8QfeT0zM/edit)

[Download the editable slides](presentation/ReView_Studio4_EN.pptx) · [Open the slide PDF](presentation/ReView_Studio4_EN.pdf)

## A seven-minute studio slot

Target **6 minutes 25 seconds**, leaving 35 seconds for slow clicks or a handoff. Joowon leads. One teammate explains a source in Explore. The other saves and reopens a reflection. These roles can be exchanged. Everyone speaks and operates the prototype at least once. The class then has about eight minutes for questions.

| Clock | Speaker and action | Words to say |
|---|---|---|
| 0:00–0:40 | Joowon · slide 1, then share the browser | “Imagine a viewer deciding whether a four-day workweek is a good idea. A long comment thread gives them many reactions, but finding the reasons behind two different views takes time. Re.View lets the viewer pick those views, hear them question one another, and check the comments behind their claims. The viewer keeps the last word.” |
| 0:40–1:15 | Joowon · Before | “I’ll open the CNBC video from the library. This evaluation has three prepared discussions, so everyone can start without a YouTube API key. I can write my own starting position, or leave it blank. I’ll start with ‘I support a shorter week if workers actually gain free time.’ That gives the comparison a specific sentence to work with.” |
| 1:15–2:25 | Teammate 1 · Explore. Expand a topic and open a stance source | “Each selectable card is a perspective we could ground in at least one comment. A topic helps me browse related positions. I can still pick any member individually. Here is the exact comment behind this stance. If I compare the card with my view, the labels distinguish agreement, difference and additional conditions. The discussion is small enough here to read the evidence for myself.” |
| 2:25–3:10 | Joowon · select two cards, start automatic debate early | “I’ll select two perspectives and ask, ‘What should a shorter-workweek pilot measure before it expands?’ Each perspective gets an opening and a reply. The question and participants stay visible. I can leave this screen or refresh and reopen the same room. You can also start an ordinary conversation and address one participant directly.” |
| 3:10–4:00 | Joowon · while it runs, show the coverage slide or the other tab | “Two numbers on Explore answer different questions. Opinion share uses the sampled comments that stated a position. Like share in the ranking uses the recorded likes that link to the displayed perspectives. The coverage panel also shows how much falls outside them. A highly liked comment can have a large effect, and some opinions link to several cards. Neither measure establishes that the viewpoint is correct.” |
| 4:00–5:05 | Joowon · return to Converse, open conclusion and one supporting turn | “Here is what the participants actually said. A turn marks which points come from a comment and which the agent inferred. For each shared claim, we can inspect who accepted it and return to the supporting turn. A consensus agent is available only when all selected participants accept a claim. We can ask it what the agreement covers. Where evidence is thin, the interface can leave disagreement or an open question visible.” |
| 5:05–6:00 | Teammate 2 · Reflect, manually save a remaining question, then open Library | “I still want to know whether the same weekly hours would be compressed into fewer days. I can keep my original opinion, select a message, and save just this remaining question. I can also ask for suggestions and decide which wording to keep. Here is my saved sentence again in the library. The system leaves that final judgment with me.” |
| 6:00–6:25 | Joowon · slide 4 | “The result we can show today is a traceable conversation and a recoverable personal reflection. Across the videos we tested, agents could also give partial answers or withhold agreement. Whether a consensus agent improves reasoning over a single agent is a question for a controlled study. For this prototype, you can inspect exactly how it got to its conclusion.” |

**If the live conclusion is still running at 4:00.** Keep the live room open. Say “This room is still generating. I’ll show a previously completed run so you can see what to inspect.” Switch to the clearly labeled result slide or your own previously saved room. Return to the live status at the end if time permits. If the live result has no agreement, show its actual outcome, continue to Reflect, and use the labeled saved example only to explain the conditional consensus feature.

**Before going on stage.** Open the public address in a fresh browser profile for the live run. Check that the room can be started without a login. Keep the deck open locally. Confirm the projector is readable, choose English in the upper right, assign the two handoffs, and rehearse with the presentation device. To use a saved room as backup, prepare it in that same profile within its 24-hour lifetime. The slides include real recorded results and also work when that room is unavailable.

## Feature reference for questions

| Where | What the audience can try | What to explain in English |
|---|---|---|
| Before | Paste a registered watch or short URL, browse analyzed videos, or start with the video on screen. | “The library reuses prepared comment analyses. A missing, expired or malformed link is explained on screen. Choosing another video changes which discussion you are reviewing.” |
| Video and language | Inspect the video preview, use the player or open the original on YouTube. Switch English/Korean, including inside dialogs. | “The language setting changes the interface and the reviewed display text for registered cards. Original comments, user writing and existing generated conversation text retain their original wording.” |
| Starting opinion | Write or clear an optional view, then save and explore. Reopen or edit it in Explore. Start over for a fresh review. | “A blank view still lets you inspect evidence, talk and reflect. Comparing a view needs some text. Editing it makes the comparisons refer to the new revision. Earlier saved work remains accessible from this browser’s Library while the session is valid.” |
| Perspective cards | Expand a topic if provided. Read the named stance and any supported reasons. Tick cards across topics, collapse and reopen a group. | “A topic is a navigation aid. Each card still has its own evidence and counts. One source can qualify a specific stance. A reason appears when we have evidence for that reason. Some registered videos show individual cards directly.” |
| Source drawer | Open the source for a stance, reason or published response. Read the original and any labeled parent comment. | “The citation supports the specific linked point. A parent comment can explain a reply’s context. Its appearance alone does not count as an additional endorsement.” |
| Comparison | Open a card’s comparison with your initial view. Inspect highlighted passages and their relation labels. Retry unavailable comparisons. | “The comparison identifies agreement, difference, an additional condition or uncertainty. The labels work without relying on color. Eligible comparisons run in the background and a saved comparison can reopen without a new inference.” |
| Perspective breakdown | Switch Opinions/Likes ranking. Expand Coverage and counting method and choose all perspectives or one card. | “Opinion share divides support for the card by sampled comments that stated a position on this issue. One comment can support several cards, so adding the rows can exceed 100%. The likes column uses linked likes, keeps likes on multiply linked comments separate, and the coverage panel shows linked and unlinked likes against all recorded likes. A missing count is shown as unavailable.” |
| Conversation setup | Select one to three perspectives in Explore, or open New chat directly in Converse and choose the format. | “One perspective opens a one-to-one chat. Two or three can hold a regular group conversation or an automatic debate. Explore offers automatic debate for eligible groups. In New chat you can choose Group conversation instead. A fourth choice leaves the first three intact.” |
| Ordinary conversation | Ask an opening question, use a suggested prompt, send a follow-up to the room or a selected participant, inspect Perspective info. Use Pause, Resume, Next round or End chat as the current state permits. | “The reply is limited by the evidence for the chosen perspective. Look at the labels on each point. A partial answer identifies a limitation. If a recoverable reply fails, Ask another question keeps the published history.” |
| Room navigation | Find rooms with All, 1:1 or Group and search their titles. Switch rooms, go to Reflect or reopen a saved room. | “Each room keeps its own participants, history and state. Returning to a running room reads its progress. It does not start another debate.” |
| Automatic debate | Enter a question, watch opening positions and replies, inspect reply targets, pause or resume when offered and use View debate conclusion. | “With two participants there are four planned speaking slots. With three there are six. Equal opportunities to speak do not imply equal supporting evidence. Stopping early, limited evidence and a verification hold are distinguishable from a verified agreement.” |
| Conclusion and synthesis | Inspect shared claims, accepting participants, conditions, supporting turns, remaining disagreements and unanswered items where present. Open a comment in the lineage or ask the consensus agent. | “All selected agents must accept the specific shared claim. The synthesis keeps the parent perspectives and their sources. A generated recommendation remains labeled as AI reasoning. A conclusion can be useful even when no consensus agent is created.” |
| Reflect | Review the initial and current opinions. Choose a room and up to 24 individual messages. Keep, clear or rewrite your current view. | “Reflect starts from your saved current text or your initial view. If you clear your draft and move between stages in the tab, it stays empty. Use my initial view brings your exact starting words back.” |
| Reflection assistance and saving | Analyze my reflection, inspect highlighted text and suggestions by category, adopt or edit the words, or write and save without AI. | “You can record what stayed the same, what changed, what you learned, and what deserves more thought. You may leave categories empty. You can save a remaining question without claiming a change of mind. Save before refreshing the page.” |
| Revisit and revise | Open a saved reflection and edit it. Reopen a linked conversation turn when a saved item carries that reference. Browse My records in Library. | “The saved reflection is versioned. The latest wording can be reopened in the same browser profile during its 24-hour session. The analyzed-video catalog is shared. Another visitor does not inherit your personal conversations.” |
| Recovery | Use Back or Escape to close Library, retry the video list after a connection failure, or use original comments and manual reflection while generation is unavailable. | “If an embed cannot play, open the original video. For a question the comments cannot support, try a narrower question or carry the uncertainty into Reflect. The app provides a route even when synthesis cannot be published.” |

## Short answers for the discussion

- **Why YouTube?** “A discussion already exists under a shared video, and replies depend on their parent comments. A viewer can compare perspectives without asking all those commenters to join another forum. We preserve the original wording so the viewer can check how we interpreted a comment.”
- **What actually runs live?** “Collection and perspective construction were completed for the three registered analyses. A visitor’s comparisons, answers, debates and optional reflection analysis run on the service. Saved results reopen. Public URL lookup opens a prepared analysis.”
- **What do the models do?** “The preparation pipeline finds candidate perspectives and checks which claims the comments support. At runtime the selected agents propose responses. A separate verifier checks evidence and response contracts. The agreement stage retains shared claims that every selected agent accepts.”
- **Does agent agreement prove that commenters agree?** “It tells us which simulated participants accepted a particular claim in this transcript. You can inspect both its reasoning and the cited source. The data do not establish a population consensus.”
- **What if the audience tries another subject?** “Our catalog includes a Korean shorter-hours discussion, an English four-day-workweek discussion and an English discussion of AI in education. It is possible to get fewer perspectives, partial replies, or no common claim. All three are useful cases for testing the interface.”
- **How would you measure whether debate helps?** “Give the initial and consensus agents the same held-out questions and source access. Blind the raters to the condition. Compare answer coverage, unsupported claims, citation support, treatment of disagreement, latency and cost. Include eligible debates that produced no agent in the overall yield. We have not established a general quality gain.”
- **What went wrong in testing?** “We found that eight 24-hour sessions could fill the entire classroom site. We separated the public admission allowance from model spending. We also gave missing-video lookups a direct route to the catalog and fixed a reflection draft that could refill after a user cleared it.”
