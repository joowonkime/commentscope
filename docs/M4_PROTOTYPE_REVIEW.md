## 7. 제출 준비의 우선순위와 범위

1. 선언한자동핵심경로를구현한다:
   선택→턴제발언→명시수락/검증→자동결론/유효합의Agent→후속질문/Reflect.
   확정계약에따라기존모듈을연결하며새로운전체재설계를시작하지않는다.
2. 같은선정영상에서대본밖질문/의견·합의없음까지실제완주하고,
   원문/조건충실도·최종답변유용성·시간/실패·비용을함께확인한다.
3. 새동작을최종Figma/프론트에연결하고초행사용자가3과업을수행하게한다.
4. 채점때까지TA가접근하고새질문을할수있는실행URL과운영설정을준비한다.
   과거실행의AI기한은종료됐다. 서버/금융권한/사용자세션/원문수명은각각확인한다.
5. 검증한버전의스크린샷/사용안내·3문장요약·도구목록·개인성찰·7분실시간시연을맞춘다.
