# 실영상 자동 토론과 단일 Agent 비교

2026-11-21 · TASK-027·037·038 · [PR #119](https://github.com/joowonkime/commentscope/pull/119)

두 실영상의 저장 댓글과 자동 생성 관점을 등록해 실제 브라우저에서 토론을 시작했다. 새 댓글 수집과 Factory 추론은 0회다. CNBC 사례에서 개시와 상대 응답 4턴, 원댓글 열람, 중복 실행 방지, 성찰 저장과 재열람을 확인했다. 두 영상에서 실제 합의 Agent는 0개였다. 이 결과는 자동 토론의 제한 검증이며, M4의 일관된 유용성과 합의 Agent 후속 질문 품질은 아직 입증되지 않았다.

시작 단계의 빈 스키마를 OpenRouter strict 모드에서 계산할 수 있는 객체 스키마로 고쳤다. 토론 생성에 JSON 종료 지시를 추가하고, 생성과 검증 양쪽에 개시·상대 응답·후속 질문의 과업을 전달한다. 합의 후보는 짧고 완결된 문장으로 작성하도록 보강했다. 실제 상대 응답에도 문장이 600자에서 잘린 사례가 있어 같은 완결성 지시를 적용했으며, 이 응답 지시의 실영상 효과는 미측정이다. 기존 원문·근거·조건 검증과 전원 수락 요건을 그대로 적용했다. CNBC 두 실행은 같은 사례의 전후 진단이다. 이후 합의 단계는 같은 저장 발언을 사용한 별도 실행이며 단일 브라우저 완주의 증거로 합산할 수 없다.

합의 단계에서 생성된 두 Agent의 수락은 모두 각자의 게시 발언을 인용했다. 그래도 Jev는 네 건 모두 입장 충실성에서 `reject`를 반환했다. 보류가 적절했는지 판별하려면 원댓글 귀속과 Agent 자신의 조건부 추론에 대한 수락을 나눠서 표기하고, 저장 후보·수락과 조건을 생략한 대조 사례를 독립 판독해야 한다. 현재 네 건을 Jev의 오판으로 확정하지 않는다.

동일 근거 비교에서 단일 Agent는 초안·자기 검토 후 질문마다 한 번 생성했다. 토론에는 별도 Jev 검증이 붙어 추론량과 판정 경계가 다르다. 현 결과는 최초 파일럿의 후속 답변 가용성을 보여준다. 답변이 생긴 경우의 상대 품질이나 상대 발언의 인과 효과는 아직 계산할 수 없다. 대조 실험을 확장할 때는 실제 관점이 갈리는 독립 사례를 고정하고, 토론 없이 별도로 작성한 관점을 같은 절차로 합치는 조건을 추가한다. 결측·보류·합의 없음은 배정된 질문 분모에 포함한다.

이번 실험에서 **OpenRouter 실제 청구는 31회, $0.266035956**이며 모델 영수증·공식 키 사용량·기존 팀 장부를 대조했다. 단일 비교용 스크립트의 프로세스 시작 실패는 모델 호출 이전에 발생했다. 금융 경로는 원래 예약액 $0.158675를 보수 차감으로 기록했고, 실제 청구액에는 이 금액이 없다. 공식 팀 잔액 $118.228728088, 보수 차감 포함 내부 장부 잔액 $111.578950738이다. 소스별 원문과 모델 출력, 브라우저 증거, 비용 문서는 비공개 `runs/real-video-debate-20261121-thuxIt/`에 있다.

## M4와 M5에서 확인할 사용자 과업

1. 새 사용자가 관점을 찾아 선택하고, 새로고침한 뒤에도 같은 토론으로 돌아가며, 원댓글과 마지막 상태를 스스로 설명할 수 있는지 확인한다. 합의가 보류돼도 근거와 남은 쟁점을 확인하고 성찰을 저장하는 흐름을 사용한다.
2. 최종 사용자 테스트의 첫 과업은 왜 두 관점이 서로 다른지 설명하고 해당 원댓글로 이동하는 것이다. 두 번째 과업은 공통 조건과 남은 이견을 짚고, 선택한 Agent의 결론이 실제 댓글 작성자들의 합의 여부를 보여주는지 판단하는 것이다. 과업 성공률, 정확한 원문을 찾기까지의 시간, 합의 오해 비율, 도움을 받은 횟수를 기록한다.
3. M5 비교에서는 댓글 원문 접근을 동일하게 제공한다. 단일 Agent 요약과 토론 결론의 제시 순서와 사례 배정을 교차하고, 실사용자 기록만 배포 평가에 포함한다. 참여자 진행문과 기록표는 비공개 실행 폴더에 준비했다. 실제 팀 외 참여자와 외부 접근 가능한 제출 URL에서의 확인은 아직 필요하다.
