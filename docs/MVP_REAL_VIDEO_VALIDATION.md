# 실영상 자동 토론과 단일 Agent 비교

2026-11-21 · TASK-027·037·038 · [PR #119](https://github.com/joowonkime/commentscope/pull/119)

## 후속 검증에서 실제 브라우저 완주

CNBC 주 4일제 영상의 기존 댓글 분석 96개와 자동 생성 관점 4개를 사용했다. 브라우저에서 두 관점을 직접 선택해 한 번 시작했다. 개시와 상대 응답 4턴, 공통 주장 2개, 각 주장에 대한 두 Agent의 검증된 수락, 계보 원문 2개가 있는 합의 Agent 1개가 같은 실행에서 저장됐다. 첫 발언은 8.3초, 결론은 45.0초에 나타났다. 진행 중 새로고침과 중복 클릭은 실행을 늘리지 않았다. 계보 원문, 새 후속 질문의 화면 답변, 성찰 저장과 재열람을 확인했다. Windows 호스트에서도 화면이 HTTP 200으로 열렸다.

마지막 구현은 세 가지 실패에 대응했다. Jev는 후보와 해당 Agent가 인용한 자기 게시 발언을 같은 입력에서 보며 생성된 수락과 실제 작성자 입장을 구별한다. 검증을 통과하지 못한 point를 제거한 뒤 남은 답변은 자체 과업 적합성과 상대 발언 연결로 판단한다. Sol은 선택적 발언 세 개를 고정 필드로 반환하며 미완성 JSON은 게시하지 않는다. 최종 브라우저 회귀는 합의, 합의 없음, 검증 보류 세 상태를 통과했다.

저장본 진단에서는 기존 합의안과 수락을 재사용하고 Jev만 다시 호출했다. 네 건 중 세 건을 검증했고, 그중 하나의 후보에 두 수락이 모여 합의 Agent를 컴파일했다. 새 브라우저 검증 전에는 개시 응답 부족과 미완성 모델 응답이 각각 한 차례 재현됐다. 마지막 실행은 별도의 파일럿 질문을 사용했다. 이 결과로 어느 변경 하나의 인과 효과를 추정할 수 없다.

실제 브라우저에서 생성된 Agent에 고정 후속 질문 세 개를 각각 새 방으로 보냈다. 두 개는 질문을 충족했고, 세 번째는 근거 없는 생산성 수치의 보장은 거절했지만 전체 댓글 작성자의 동의 여부에는 답하지 않아 부분 응답으로 평가했다. 두 번째와 세 번째 질문은 제품 HTTP API에서 확인했다. 한 영상의 내부 검토다. 여러 영상에서의 일관성, 같은 근거를 받은 단일 Agent 대비 개선 효과, 제출용 외부 URL과 팀 외 초행 사용자 평가는 남아 있다.

후속 검증 전체는 **35회, $0.189536150**이며, 최종 브라우저 토론과 후속 질문 세 건은 **20회, $0.092390226**이었다. 팀 키의 공식 잔액은 **$118.039191938**이다. 영수증·공유 장부·공식 사용액이 일치했고 미확정 과금은 0건이다. 신규 Factory 모델 호출은 0회다. 로컬 증거는 `runs/mvp-ratification-20261121-zph6lw/wire-check/`에 보관했다.

### 두 QA 결함 수정 후 재검증

- 같은 실댓글 분석에서 초기 의견을 비워 두고 Explore를 열었다. 카드의 입장 원문과
  이유 원문을 각각 클릭해 해당 출처의 본문이 열리는 것을 확인했다. 두 열람에서 생성 요청은 없었다.
- 이전에 게시된 잘못된 요지 네 개는 지시를 강화한 독립 모델도 모두 통과시켰다.
  코드 검사는 주간 총시간을 일일 시간으로 옮긴 네 요지를 모두 보류했고, 함께 저장된
  나머지 일곱 요지는 이 검사에서 통과했다. 올바른 시간 환산, 명시적인 별도 비교,
  합의 후보에 들어간 시간 단위 오류도 합성 검사에서 대조했다.
- 같은 두 참가자, 같은 질문으로 실제 브라우저에서 다시 실행했다. 첫 발언 6.07초,
  결론 42.27초. 게시한 4턴의 요지 8개에 이전 단위 오류는 없었다. 발언 3턴은
  부분 응답이었고 최종 합의는 검증 보류였다. 원문 열람, 성찰 저장과 재열람까지 진행했다.
- 재검증은 브라우저 모델 14회와 저장 발언의 독립 재판정 4회를 사용했다.
  실제 청구는 각각 $0.081460428과 $0.000719796이었다. 준비 과정에서 로컬 검증
  프로세스 시작 실패로 잡힌 $0.011010048은 보수 차감으로 남겼으며 공식 청구는 없었다.

이 결과는 한 등록 분석과 고정된 질문에 대한 제품 QA다. 검증된 시간 단위 오류의 재현 범위와
실제 게시 흐름을 기록하며, 새 댓글 분석이나 초행자 사용성의 일관성 판정은 완료하지 않았다.

합의 단계에서 생성된 두 Agent의 수락은 모두 각자의 게시 발언을 인용했다. 그래도 Jev는 네 건 모두 입장 충실성에서 `reject`를 반환했다. 보류가 적절했는지 판별하려면 원댓글 귀속과 Agent 자신의 조건부 추론에 대한 수락을 나눠서 표기하고, 저장 후보·수락과 조건을 생략한 대조 사례를 독립 판독해야 한다. 현재 네 건을 Jev의 오판으로 확정하지 않는다.

## M4와 M5에서 확인할 사용자 과업

1. 새 사용자가 관점을 찾아 선택하고, 새로고침한 뒤에도 같은 토론으로 돌아가며, 원댓글과 마지막 상태를 스스로 설명할 수 있는지 확인한다. 합의가 보류돼도 근거와 남은 쟁점을 확인하고 성찰을 저장하는 흐름을 사용한다.
2. 최종 사용자 테스트의 첫 과업은 왜 두 관점이 서로 다른지 설명하고 해당 원댓글로 이동하는 것이다. 두 번째 과업은 공통 조건과 남은 이견을 짚고, 선택한 Agent의 결론이 실제 댓글 작성자들의 합의 여부를 보여주는지 판단하는 것이다. 과업 성공률, 정확한 원문을 찾기까지의 시간, 합의 오해 비율, 도움을 받은 횟수를 기록한다.
3. M5 비교에서는 댓글 원문 접근을 동일하게 제공한다. 단일 Agent 요약과 토론 결론의 제시 순서와 사례 배정을 교차하고, 실사용자 기록만 배포 평가에 포함한다. 참여자 진행문과 기록표는 비공개 실행 폴더에 준비했다. 실제 팀 외 참여자와 외부 접근 가능한 제출 URL에서의 확인은 아직 필요하다.
