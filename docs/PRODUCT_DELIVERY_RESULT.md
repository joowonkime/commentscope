## 실제로 추가한 동작

별도 `/mvp` 화면에서 초기 의견 입력 → 자동 관점 비교 →1:1 또는 그룹 대화 → 원문 → 성찰 제안/편집/저장/재열람을 수행한다.
SQLite가 의견 revision·room·게시 메시지·job·성찰 revision을 보존한다. 초기/현재 의견과 AI 제안, 사용자 저장본을 구별한다.
기존 M0 API, 팀 프론트와 Figma는 유지했다.

| 단계 | 제한된 실제 모델 확인 |
| --- | --- |
| 등록 | 과거 Factory가 자동 생성한 합성 snapshot의 전체2Agent를 현재 compiler로 등록 |
| Explore | 초기 의견과 두 관점의 비교2회, 각각2/5개 항목. 첫 비교 재요청은 같은 job 재사용 |

| 원문 | 게시 항목의 실제 source와 인용 구간 일치 확인 |
| Reflect | 네 범주 제안 각1개, 사용자 수정 후 저장 revision2를 재열람 |
| 비용 | `openai/gpt-5.2`, OpenAI 고정, 실제9회 영수증 합계 **$0.048202** |

이는 **실제 모델 응답 / 합성 댓글 자료**의 기능 확인이다. 실제755/999개 댓글이나 임의 영상 분석을 완료하지 않았다.
본 사이클의 기존 보수 차감도 유지했다. $5 한도 중 누적 차감 $0.96962145, 잔여 $4.03037855다.
