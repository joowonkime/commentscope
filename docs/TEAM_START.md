# 조원 시작 안내

## 지금까지의 결론

댓글을 관점별로 묶고 그 근거를 가진 Agent를 생성하는 코드 초안과, 두 관점에게 질문하고 원문을 보는 백엔드 흐름을 만들었다. 제한된 실제 자료에서 Agent 2개·각 지지 댓글 3개와 6응답을 확인했다. 전체 댓글의 의미를 충분히 살리는 자동 분석 품질은 미완료다.

지금 함께 이어갈 일은 초안의 개선, 프론트 연결, 결과 검토와 사용자 테스트 준비다. 자세한 수치는 [상세 현황](TEAM_STATUS.md)에 있다.

## 처음 받아서 작업하기

1. [저장소](https://github.com/joowonkime/commentscope)의 Code → Download ZIP 또는 코딩 에이전트의 GitHub 연결로 받는다. 직접 Git을 쓰면 `git clone https://github.com/joowonkime/commentscope.git`을 실행한다.
2. 수정·PR 제출에는 에이전트의 GitHub 로그인과 쓰기 권한 또는 fork 권한이 필요하다. ZIP에는 Git 이력이 없으므로 아래 요청으로 checkout부터 맡긴다.
3. 수정할 내용을 아래 문장에 넣어 코딩 에이전트에 전달한다.

> 프로젝트는 https://github.com/joowonkime/commentscope 야. ZIP으로 받았다면 기존 폴더를 보존하고 Git 저장소를 새 폴더에 받아줘. README.md와 AGENTS.md를 읽고, [수정할 내용]을 구현해줘. 작업 브랜치를 만들고 검사한 뒤 main 대상 PR까지 제출해줘. 확인 방법과 결과를 쉬운 말로 설명해줘.

에이전트가 파일 읽기와 터미널 또는 GitHub 쓰기를 지원해야 한다. AGENTS.md를 자동 인식하지 않는 도구에는 위처럼 직접 읽으라고 요청한다. 지침 파일만으로 권한 부여나 무인 실행이 이루어지지는 않는다.

## 화면과 코드 확인

Python 3.12 이상에서 합성 화면을 실행한다. GPU·모델·API 키·추가 패키지는 필요 없다.

```bash
cd src
python -m commentscope.agents.team_demo --session-dir ../runs/team-demo
```

http://127.0.0.1:8766 에서 두 관점을 선택해 입장·이유·비용을 질문한다. 합성 예시이므로 실제 클러스터링 성능으로 해석하지 않는다. 저장소 루트에서 `python tools/check_factory_draft.py`로 연결·출처·집계 계약을 검사할 수 있다.

## 변경 결과는 어디로 가나

에이전트가 작업 브랜치를 올리고 `main` 대상 PR을 만든다. PR은 공통 코드에 합칠 변경 제안이다. 에이전트가 준 링크에서 설명과 검사 결과를 확인하면 된다. 팀이 합친 내용은 다음 사람이 받는 `main`에 포함된다.

쓰기 권한이 없으면 본인 계정의 fork로 PR을 보낼 수 있다. 직접 함께 작업하려면 소유자가 Settings → Collaborators에서 조원 계정을 초대한다. 실제 댓글·개인 대화·키·모델 파일은 올리지 않는다.
