기준일: 2026-10-23. 현재 전체 기능 중 구현된 부분과 검증 범위의 정본이다.

2026-10-24 추가: 클러스터링 → Agent 생성 코드의 공동 수정은 [파이프라인 개발 안내](PIPELINE_DRAFT.md)를 따른다. 모듈별 담당 위치·입출력·개인 브랜치/PR 절차를 정리했다. 저장소 루트에서 `python tools/check_factory_draft.py`를 실행하면 GPU 없이 합성 자료로 연결·출처·집계 계약을 검사한다. 실제 모델 품질 검증은 포함하지 않는다.

## 이전 판정 문제와 수정의 유효성

**과거 수정 전부의 효과를 입증하지는 못했다.** 코드 검사 통과, 모델 자체검사 통과, 실제 제품 개선은 서로 다르다.

- 현재 경로에서 확인: 정확한 부모 연결·검토 전 집계 금지·초기 의견/이력 분리·이유 질문에 입장으로 대체 답변 금지.
- 효과 미입증: 여러 문장/논거 추출·타입 판정 실험. v12·v13은 새 유효 지지0개였다. 이를 성능 개선으로 세지 않는다.
- 실패 보존: 최초6응답 중1건은 이유 대신 입장을 답했다. 다음 실행은 빈enum 스키마가 서버에서 거부됐다. 두 실패를 보존하고 최종 경로를 수정·재검증했다.
- 최종 제한된 확인: 원문6건/Agent2개/실제6응답 검토, HTTP3라운드6응답 통과. 답변3건·적절한 보류3건이다.

직접 대조는 개발에 참여한 주Agent가 수행했으므로 독립gold가 아니다. 검증기 자체의 전체 정확도나 과거 변경 전체의 인과적 개선 효과는 미입증이다. 변경 전후를 같은 고정 표본·같은 판정표로 비교하고 별도 검토자를 통한 확인이 추가로 필요하다. 공개 가능한 수치는 [검증 요약](examples/backend-validation-summary.json)에 있다.

## 조원이 바로 실행하는 화면/API 확인

Python3.12 이상이 필요하다. **합성 연동 데모**이므로 GPU·모델·API키가 필요 없다. 실제 댓글/모델 품질의 시연은 아니다.

```bash
git clone https://github.com/joowonkime/commentscope.git
cd commentscope/src
python -m commentscope.agents.team_demo --session-dir ../runs/team-demo
```

이 실행은 Python 표준 라이브러리만 사용한다. 가상환경·pip 설치 없이 확인할 수 있다. 이미 저장소를 받았다면 `main`을 최신으로 갱신하고 `src` 폴더에서 실행한다.

브라우저에서 **http://127.0.0.1:8766**을 연다. 포트가 사용 중이면 `--port 8767`, 종료는 `Ctrl+C`.

| 해 볼 동작 | 기대 결과 |
| --- | --- |
| 초기 의견 입력→두 관점 선택→새 대화 | 의견 원문·선택 저장 |
| `핵심 입장은 무엇인가요?` | 서로 다른 두 합성 입장과 자기 출처 |
| `이유와 조건은 무엇인가요?` | 이유가 있는 관점만 자기 이유를 답하고 다른 관점은 보류 |
| 원문 버튼 클릭 | 자기 합성 원문, 답글의 부모는 별도 문맥으로 표시 |
| `정확한 시행 비용은?` | 둘 다 보류 |
| 새 대화/다른 브라우저 | 이전 이력과 분리 |

합성 데모 provider는 정해진 질문/역할을 처리하며 다른 질문은 기본 보류한다. 자동 관점 생성·실제 모델 성능·앞선 실제 검증의 증거로 사용하지 않는다. 조원 화면을 대체할 목적이 아니라 API 동작을 확인하기 위한 실행기다. Figma 원본은 변경하지 않았다.

## 실제 댓글·Qwen 검증은 어떻게 확인하나

기존 저장소 정책대로 실제 댓글·corpus·ledger·모델 응답은 Git에 포함하지 않는다. **저장소 clone만으로 실제 실험까지 재현할 수는 없다.** 공개 요약만으로 독립 의미 품질 검증이 가능한 것도 아니다.

- 작성자의 기존 개발환경에서 실제 완료 응답으로 HTTP 재현: [전달 자료](COMPARE_BACKEND_DELIVERY.md).
- 새 질문을 실제 Qwen으로 실행하려면 검토된 bundle과 기존 Qwen 서버(port8091)가 필요하다.
- 독립 검토는 실제 원문·부모·생성 내용·검토표를 비공개로 인계받아 수행한다. 현재 고정 snapshot 사용 기한은2026-11-08이다.

## 프론트 연결과 다음 작업

`POST /api/session`→`POST /api/ask`→`GET /api/state`→`POST /api/source` 순으로 연결한다. 토큰·JSON 필드는 [API 계약](COMPARE_BACKEND_API.md)을 따른다. 별도 프론트 서버는 같은origin을 위한 프록시 설정이 필요하다. Factory는 매 질문마다 다시 실행하지 않는다.

우선순위는 **프론트/API 연결→함께 화면 점검 및 Figma 변경 합의→[사용자 테스트 과업](COMPARE_BACKEND_USER_TEST_TASKS.md) 수행**이다. 전체 Factory 개선·독립 평가는 별도로 남아 있다.
