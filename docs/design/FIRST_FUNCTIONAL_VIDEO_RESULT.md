## 입력과 실행 범위

[CNBC 주4일제](https://www.youtube.com/watch?v=RrFaNO3rTaA)의 공식API bounded snapshot240개
(root153/reply87)에서 canonical ID의 고정 hash 순으로 root64/reply32,96개를 처리했다.
별도 root16/reply8,24개는 발견·지지 집계에서 제외했다. 부모 원문은 문맥으로 보존한다.
표시 댓글938개 전수나 기존UBI999/r5 평가를 대체하는 실행이 아니다.

자동 발견에서 후보32개가 나왔다. 후보당 최대12출처·전체192선택쌍/48출처로 관계를 검증했다.
특정 관점이나 Agent를 수작업으로 넣지 않았고 조건·불확실성·작성자 귀속·필수 사실·최소3유효지지를 유지했다.

사실 근거로 [UKRI 공식 기사](https://www.ukri.org/who-we-are/how-we-are-doing/research-outcomes-and-impact/esrc/making-the-case-for-a-four-day-working-week/)
원문11구간을 공급했다. 영국2022년61개 자발적 참여 조직의 시험 범위를 모든 업종의 보장된 효과로
일반화하지 않았다. 최종 bundle이 비어 외부사실 판정 요청은0회였으므로 문서 공급의 품질 개선 효과는
이번 실행에서 입증하지 못했다. 기존 Kela UBI 자료는 사용하지 않았다.
확인용24개 중7개 사례를 실행 전에 assistant가 정성 검토했지만 독립 사람 gold나24개 전수QA가 아니다.

## 코드와 검사

새 회귀9개·명세18개·필수Factory910개(272.073초)가 통과했다.

CI 뒤 실제 가격·키150한도·장부·자원·기한을 확인하고 새3시간/1200물리요청 실행을 등록했다.
같은 누적150달러 계정·기존 금융owner·과거 차감을 유지하고 종료된 실행은 재개하지 않았다.
이 검사는 실행 보호·코드 회귀이며 의미 품질 합격이 아니다.

## 확인된 구조적 손실과 아직 모르는 것

**검색 배분:** 현재 검색은 후보별 최대12쌍을 먼저 채운 뒤 다음 후보로 넘어간다.
32후보 중17개만 비교됐고15개는0쌍이다. 일부32시간/40시간·업종·임금 관련 후보가 여기에 포함된다.
미평가 후보의 지지0은 지지하는 댓글이 없다는 증거가 아니다.
발견 당시 nominee43쌍/서로 다른42출처는 기존192쌍/48출처 상한 안에 모두 들어간다.
그런데19 nominee쌍이 미평가였다. 입력 부족과 별개로 배분 순서가 범위 손실을 만든다는 근거다.
nominee는 모델 제안이며 실제 지지 승인이 아니다. 배분 변경 후 Agent 증가량은 미검증이다.

**원문 감사:**10개 unresolved에는 단위 충실도·추론/의존 관계·전체 coverage 불일치가 포함된다.
이 중 필요한 보류와 과도한 보류의 비율은 독립 평가하지 않았다.
1개 주소 결합 실패도 원문을 임의로 자르거나 모델 답을 재작성해 구제하지 않았다.

**후보 연결:** 감사된8원문의 전체 텍스트와 후보 연결 기록을 assistant가 대조했다.
두 기록은 이미 검증된 source graph의 이유/양보 목록과 새 후보 응답의 재생성 목록이 달라
`candidate_inventory_incomplete`로 보류됐다. 그중1개는 별도의 표현 불가도 있다.
다른1개는 개인 근무 경험의 사실 범위와 position/core-fact ID 선택이 충돌했다.
어느 관측이 의미적으로 맞는지 추가 독립 비교가 필요하다.

**후보 간 결합:** 한 원문에서 후보3개 중1개의 범위 판정만 실패하고2개 증서는 적격이었다.
하지만 `source_evidence_adapter.lower()`는 모든 증서의 보류를 단일 source 상태에 합쳤고,
`audit()`는 그 source의 모든 단위를 미검증 처리했다. 기존 `candidate_source_coverage.project()`는
legacy `owned_arguments`만 지원해 새 source-evidence 기록의 적격 peer를 분리하지 못했다.
이는 코드와 저장 산출물에서 확인한 책임 결합이다. 원문 전역의 실패와 후보별 실패를 분리할
일반 계약이 필요하다. 이 문서/실험에서 해당 동작을 수정하거나 적격 Agent 증가를 입증하지 않았다.

따라서 이번 결과를 댓글에 제대로 된 주장이 없거나3이라는 숫자 자체가 잘못됐다는 결론으로 쓰지 않는다.
새 영상·영어 표본·작은96개 범위가 동시에 달라졌으므로 기존UBI 결과와의 성능 인과 비교도 아니다.
