## 선택한 계약

- opt-in `supported-parent-retrieval-20261110-v1`. 기본/legacy alias 정책은 유지한다.
- 입력은 현재 source, 초기 후보/nomination, 재구성 가능한 consolidation/동치 판정,
  실제 최종 문구 memberships와 이미 시도한 pair다. 평가 label·정답·좋은 과거응답을 입력하지 않는다.
- consolidation을 원래 증거로 재구성하고 각 membership을 기존 collector로 검증한다.
  실제 supported인 세부 후보에서 E1의 `a_narrower/b_narrower` 방향을 따라 한 단계 부모 후보를 찾는다.
- alias→현재 canonical ID를 복원한다. equivalent/uncertain/opposed/different는 부모 관계로 쓰지 않는다.
- 원문별 canonical 부모 최대3개만 새 검색한다. 순서는 안정된 ID순서다. 초과는 미평가로 보고한다.
  후보를 전부 비교하거나 무한 재귀하지 않으며 추가 pair 상한은3N이다. 추가 embedding/전용 LLM관측은0이다.
- 기존 시도/판정과 중복된 pair는 제외한다. 실패했던 요청을 다른 stage 이름으로 자동 재시도하지 않는다.
- 출력은 새 검색 pair·범위/상한 보류·provenance이며 semantic approval과 membership은 없다.
  모든 새 pair는 기존 전체 원문 비교·귀속·조건·유형/전제 검사로 직접 판정한다.

`only if` 후보가 부모 mandatory 후보의 검색으로 이어져도 지지는 자동으로 이전되지 않는다.
부모 원문 검증이 conditional/rejected이면 그 상태가 유지된다. 다른 작성자의 이유도 옮기지 않는다.
한 source의 이미 승인된 세부 지지는 삭제하지 않는다. 실제 공유 활용은 최종 직접 지지로만 센다.
