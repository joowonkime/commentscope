  Host가 원문/문헌 ID·구간·기한·지지 수·비용을 결합한다. 자동 재생성은 없다.
- 발언의 `original_comment / ai_reasoning / external_evidence`를 실제1:1·그룹 API/기록/화면에 연결했다.

  새 논거가 댓글 지지 수를 늘리지 않는다. 외부자료는 준비된 topic pack이며 새 웹검색이 아니다.

  상태18조합과 origin/reference 조합을 생성 schema와 Host에서 일치시켰다.

CNBC 저장96입력의 원문/모델 관측을 **새 추론0회**로 재조립해 profile4개를 만들었다.
