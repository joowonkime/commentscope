## 다음 구조 개선을 판단할 근거

이번 확대는 후보 검색 범위가 실제로 결과에 영향을 줌을 보여준다. 기존 좋은 생각 profile의
지지가4→5로 늘고 시행 profile이 추가됐다. F4에서는 과거에 없던 후보 증서도 완성했으므로
증가분 전부를 검색 폭 하나의 인과 효과로 분리하지는 않는다.

다음 검토는 원문 해석/주소/전체 감사에서의 손실과 실질적 관점 구별·이유/조건의 전달을
우선한다. 현재 요청되는 모든 의미 필드가 필요한지, 모델 오류와 host 표현 제약을 어떻게
분리할지 저장된 실패를 먼저 대조한다. 특정 댓글 정답에 맞춘 재시도나 최소 지지 완화는 하지 않는다.
전체 구조 교체가 필요하다는 결론이나 어떤 대안의 품질 개선 효과가 입증된 상태는 아니다.

실행·검토는 완료됐고 활성 유료 작업은 없다. 전체 r5(453/755 등), 의미가 구별되는 유용한
2관점, 임의 질문/그룹 대화·초행 TA의 시나리오 이탈 검증과 전체 MVP 완료는 아직 미달/미검증이다.
