## 오류와 중단

Jev의 닫힌 선택지 응답이 모순되거나 누락된 오류8건을 저장했다. 해당 관측을 보류했으며
그 오류에 맞춘 prompt 변경·판정 완화·추가 유료 재시도는 하지 않았다.
독립 M2의 일부 저장 관측에서도 전체 원문에 있는 수혜 범위 조건이 선택 근거에 빠진 정황을
개발 에이전트가 발견했다. 최종 membership/논거/Compiler가 이를 보류하는지 아직 확인되지 않아
최종 집계 오류로 단정하지 않는다. 모델 자체 판정과 원문 대조, 독립 사람 gold는 서로 다르다.

두 중단은 Windows host의 commit 여유가 고정 최소1GiB보다 작아져 발생했다.
첫 중단의 여유는629473280바이트, 같은plan 재개의 두 번째 중단은969764864바이트였다.
983개 응답/체크포인트와 모든 정산을 보존했고 재개 중 새 유료 응답은0건이었다.
로컬 LLM 가중치를 로드하지 않았으며 OpenRouter가 추론을 수행했다. host 메모리는 실행기와
다른 Windows/WSL 앱이 함께 사용한다. 비용 한도 초과나 OpenRouter 모델 메모리 요구로 중단된 것이 아니다.

프로세스 한정 allocator 설정으로 재개했지만 보호 기준에 다시 걸려 개선을 입증하지 못했다.
자원 보호 기준을 낮추거나 다른 앱을 임의 종료하지 않는다. 호스트 여유를 확보한 뒤 같은
frozen plan과 저장 응답으로 재개하며, 원래 단계 deadline/예산/원문 기한을 유지한다.
