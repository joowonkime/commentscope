# Product assets

The SVG assets are downloaded from the team's existing Re.View Figma design,
file `Q5oqIs2ekQIagiboAFX7Qc`, for the before/explore/comparison/conversation/reflection screens.
The Figma source remains unchanged. Temporary MCP download URLs are not runtime dependencies.

Inter and Geologica are self-hosted variable WOFF2 fonts, converted from the upstream
Google Fonts files with fontTools 4.68.0. Their SIL Open Font License texts are included
as `Inter-OFL.txt` and `Geologica-OFL.txt`.

- [Inter source](https://github.com/google/fonts/tree/main/ofl/inter)
- [Geologica source](https://github.com/google/fonts/tree/main/ofl/geologica)

These assets provide visual presentation. Character art does not imply a real author's
occupation, identity, or experience. The API supplies all positions, source counts,
grounds and conversation contents.
